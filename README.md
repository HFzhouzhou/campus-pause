# 校园暂停键 · Campus Pause

> 为大学生打造的极简深色毛玻璃 HUD 风格校园减压 Web 应用（Mobile-First 响应式设计，零配置开箱即演示，支持平滑迁移至微信小程序 / 云开发）。

## ✨ 核心视觉与设计理念

- **拒绝传统心理咨询软件的沉闷与说教**：采用深空灰/夜幕蓝 (`#0B0F19`) 基调 + 薄荷绿 (`#34D399`) / 日落琥珀 (`#FBBF24`) / 静谧薰衣草 (`#A78BFA`) 柔和治愈光晕 + 半透明毛玻璃 HUD（对标 DJI Fly 与高端冥想应用）。
- **悬浮式胶囊导航栏 (Floating Bottom Dock)**：单手即可在「治愈地图 / 情绪粉碎 / 焦虑拆解 / 限时搭子」四大核心模块间顺滑切换。
- **零配置防白屏**：未填写任何 API Key 时，地图自动降级为高颜值交互式暗黑矢量校园地图，AI 焦虑拆解自动启用本地智能关键词 + 打字机流式引擎，所有 UGC 与互动数据自动持久化到 `localStorage`。

## 🗺️ 如何申请并配置高德地图 JS API 2.0 Key

未配置时应用会自动无缝降级为**交互式暗黑矢量校园地图**（支持缩放、拖拽、点击/准星选点与全部 UGC 功能）。如需启用真实高德地图与卫星图层：

1. 访问 [高德开放平台控制台](https://console.amap.com/dev/key/app) 并登录。
2. 进入 **应用管理 → 我的应用 → 创建新应用**。
3. 点击 **添加 Key**，服务平台务必选择 **「Web端 (JS API)」**。
4. 创建完成后，复制页面中显示的 **Key** 以及 **安全密钥 (jscode)**。
5. 在项目根目录新建 `.env.local`，填入：

```env
VITE_AMAP_KEY=你的高德Web端Key
VITE_AMAP_SECURITY_CODE=你的高德安全密钥jscode
```

6. 重启 `npm run dev`，即可体验高德暗黑风格 (`amap://styles/darkblue`) 与卫星航拍图层的实时切换。

### 🤖 (可选) 配置焦虑拆解大模型流式 API

同样在 `.env.local` 中配置任意兼容 OpenAI `/chat/completions` 流式格式的接口（如 DeepSeek、OpenAI、通义千问、Kimi 等）：

```env
VITE_LLM_API_URL=https://api.deepseek.com/v1/chat/completions
VITE_LLM_API_KEY=sk-xxxxxxxx
VITE_LLM_MODEL=deepseek-chat
```

## 🎯 四大核心模块与完整演示路径

### 1. 校园治愈地图（默认首页 · 对标 DJI Fly 交互）
- **DJI Fly HUD 与图层切换**：顶部毛玻璃搜索框 + 横向滚动分类胶囊（绝美落日、流浪猫基地、极静自习、躺平草坪、吹风天台）；右侧悬浮控件支持一键切换「暗黑 / 卫星」图层、缩放与复位中心。
- **双向联动点位卡片流**：点击地图上带呼吸发光外圈的圆形缩略图点位，底部卡片流自动平滑滚动居中；左右滑动卡片，地图自动平移聚焦对应点位。
- **实时安静度与匿名打卡**：点击卡片「去这里 / 查看详情」拉起详情抽屉，可一键更新此刻状态（很安静 / 人不多 / 有点吵）并发布匿名治愈足迹。
- **UGC 自主标记新治愈点**：
  1. 点击右下角 **「+ 标记治愈点」** 进入选点模式。
  2. 直接点击地图任意位置，或拖动地图对准屏幕中央准星，实时回填经纬度。
  3. 点击确认后打开上传表单，支持本地图片 **Canvas 自动压缩转 Base64**（或快选内置治愈预设图）、填写名称/分类/1-5 星安静指数/安利理由。
  4. 提交后立刻在地图上点亮新地标并持久化到 `localStorage`。

### 2. 30 秒情绪粉碎机 (Instant Vent) + 隐形心理安全兜底
- **快捷宣泄与静音声波**：支持一键填入大学生高频崩溃标签（如“高数看不懂了”、“小组作业全是我做”、“秋招 0 Offer”），或长按 **「吼一嗓子」** 静音声波按钮释放压抑感。
- **黑洞漩涡粉碎爽感**：点击 **「彻底粉碎」**，文字卡片揉皱旋转吸入黑洞粒子动画，同时通过 **Web Audio API** 实时合成撕纸与黑洞吸入音效，并触发手机震动 (`navigator.vibrate`)，阅后即焚绝不留存。
- **同校共鸣墙（无评论区）**：严格关闭评论区杜绝二次内耗，仅允许点击 **「🫂 抱抱」** 或 **「⚡ 同感」** 并飘出暖心粒子动效。
- **隐形安全兜底演示**：在输入框中输入包含高危词（如 `撑不住了` / `不想活`）并点击粉碎，粉碎完成后不会弹窗吓人，而是温和浮现一张暖光关怀卡片，提供 **「校园心理中心 24h 匿名绿色预约通道」** 与全国 24h 公益心理援助热线。

### 3. 焦虑拆解 AI (Micro-Step)
- 输入让人卡死的大事（或点击快捷示例“后天考线代还没复习”、“下个月毕业论文初稿没动”），流式拆解为 **3 个现在花 10 分钟就能干完的极小微步骤**。
- 点击任意步骤的 **「立刻开启 10 分钟专注」** 启动极简圆环倒计时（弹窗底部内置 **5 秒极速演示** 入口），完成后自动打钩、播放治愈和弦并绽放全屏粒子烟花。

### 4. 无负担限时搭子 (Zero-Burden Buddy)
- 卡片流展示校园 30 分钟轻度活动，每张卡片实时跳动倒计时，并明确标注 **「活动结束自动解散 · 不强制加微信」** 边界承诺。
- 点击 **「举手加入」** 弹出临时暗号与零压力快捷轻聊室；点击 **「+ 发起 30 分钟限时搭子」** 可发布自己的限时搭子并持久化保存。
